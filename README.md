# Sound Effects

Koleksi sound effect buat game & project. File audio (mp3 / ogg / wav) disimpan di folder `sfx/`.

## Cara pakai di web / game

Jangan pakai link raw GitHub — pakai **jsDelivr** (CDN gratis, cepat, ke-cache):

```
https://cdn.jsdelivr.net/gh/xhamzar/sound-effects@main/sfx/nama-file.mp3
```

Ganti `nama-file.mp3` dengan nama file yang ada di folder `sfx/`.

## Nambah sound baru

- Kirim file-nya ke Cia, nanti di-upload ke sini.
- Atau upload langsung lewat web GitHub (Add file → Upload files) ke folder `sfx/`.
- Atau `git push` seperti biasa.

## Batas GitHub

- Maksimal **100 MB per file** (di atas 50 MB sudah muncul peringatan).
- Total repo sebaiknya di bawah **1 GB**.
- File di atas 100 MB pakai Git LFS.
